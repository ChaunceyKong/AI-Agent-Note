# 任务系统

为了使Agent更够跨步骤、跨阶段协调工作，把“会话里的 todo”升级成“可持久化的任务图”。

## 名词解释

`task`：一个可以被跟踪、被分配、被完成、被阻塞的小工作单元；

`依赖`：任务B必须等任务A完成后才能开始；

`任务图`：任务节点+任务连线。点：每个任务，线：谁依赖谁；

`ready`：这条任务现在已经满足开工条件；

## 最小心智模型

```
1、现在有哪些任务？
2、每个任务是什么状态？
3、哪些任务还被卡住？
4、哪些任务已经可以开始？
```

## 最小数据结构

1、taskRecord

```python
task = {
    "id": 1,
    "subject": "Write parser",
    "description": "",
    "status": "pending",
    "blockedBy": [],
    "blocks": [],
    "owner": "",
}
```

`id`：任务的唯一标识；

`subject`：这条任务的目标，在做什么；

`description`：任务的补充说明；

`status`：任务状态；

`blockedBy`：该任务依赖哪些其他任务；

`blocks`：该任务完成后，会解锁谁；

`owner`：现在由谁来做；

2、TaskStatus

```
pending -> in_progress -> completed
deleted
```

3、Ready Rule

```python
def is_ready(task: dict) -> bool:
    return task["status"] == "pending" and not task["blockedBy"]
```
